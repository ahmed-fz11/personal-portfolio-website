## Stack

Next.js (App Router) · TypeScript · Tailwind CSS · [next-themes](https://github.com/pacocoursey/next-themes) for dark/light mode · [EmailJS](https://www.emailjs.com/) for the contact form

## Running locally

```bash
cd frontend
npm install
npm run dev
```

Opens on [localhost:3000](http://localhost:3000).
